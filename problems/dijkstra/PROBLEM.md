# Shortest path

Input: the first line holds `N M`: the number of nodes (numbered 0 to
N-1) and the number of edges. Then M lines follow, each `u v w`: an
undirected edge between u and v with positive integer weight w. The last
line holds `s t`: the start node and the target node.

Output: one integer: the length of the shortest path from s to t, or `-1`
if no path exists. If s equals t the answer is 0.
