# Expression calculator

Input: one arithmetic expression per line. An expression holds
non-negative integers, the operators `+ - * /`, parentheses, and spaces.
There are no unary operators. Division is integer division that truncates
toward zero. No expression divides by zero.

Output: the value of each expression as an integer, one per line.
Apply the usual precedence: `*` and `/` before `+` and `-`, left to right
within the same level.
